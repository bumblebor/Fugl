# README
## How to install
* Install NodeJS from [NodeJS](https://nodejs.org/en/download) 
* Open up https://github.com/bumblebor/Fugl in a web browser
* Click on "<> Code"
* Click "Download ZIP"
* Save the zip file to your downloads folder
* Extract the file
* Open the extracted file and navigate to the source directory
* Double click "start.sh"
  * The first run may take a while longer because Fugl needs to install dependencies
* Once the dependencies are installed, wait for the console to display a number
## How to use
* To start the program, double-click start.sh
* Once the console displays a number, you can begin finding fair prices between different airports using the dropdown menues
* To find the fair price between airports, click "Submit"
